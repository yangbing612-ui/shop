# 解析数据

## 触发条件
当用户说以下词语时触发：
- 解析数据

## 参数

### 1. 文件夹
- **参数名**：文件夹
- **类型**：字符串
- **必填**：是
- **描述**：目标文件夹名称，将在public文件夹中查找

## 执行步骤

### 1. 执行解析脚本
```bash
python parse_data.py "{{文件夹}}"
```

### 2. 提示完成
解析完成后，向用户报告：
- 解析是否成功
- 生成的产品数据信息
- 如有错误，显示错误信息

## 注意事项
- 确保目标文件夹存在于public目录中
- 解析过程会自动处理大文件，避免仓库体积过大
- 解析结果会追加到products.json文件，不会覆盖现有数据
